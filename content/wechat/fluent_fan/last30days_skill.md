## 手把手教学：如何为你的 AI 助手装上“情报外挂”？

配置过程极其简单，通常只需要在支持 Agent Skills 的环境中执行：

### 第一步：一键添加技能
如果你正在使用支持 `skills` 命令的智能体（如 Claude Code 或相应的命令行 AI）：

```bash
# 一键添加该远程技能到你的智能体中
npx skills add https://github.com/mvanhorn/last30days-skill
```

### 第二步：配置你的 API 密钥 (可选)
为了获得更精准的社交平台数据（如 Reddit 或 Twitter），你可以在本地 `.env` 文件中配置相应的免费只读 Key：

```bash
# .env 文件配置
REDDIT_CLIENT_ID="your_reddit_id"
REDDIT_CLIENT_SECRET="your_reddit_secret"
```
*(如果不配置，技能会自动回退到无 Key 的公共数据抓取，依然能够正常运行)*

### 第三步：让 AI 开始为你打探情报

你只需要在终端中对你的 AI 发出指令：

```bash
# 启动智能体并执行情报收集
claude-code "run last30days-skill research 'Remote Software Engineering salary trends' --output report.md"
```

AI 会自动开始跑流程，几秒钟后，一份沉甸甸的、带真实链接的 `report.md` 就会躺在你的文件夹里了！

## 爽过之后的冷静思考：它有什么局限？
