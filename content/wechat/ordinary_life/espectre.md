# 无摄像头防窥！今天爆火的 ESPectre，把家里的 Wi-Fi 变成最强防盗雷达！

## 监控地狱：为了防小偷，我们却在家里塞满了“窥探隐私的眼睛”？

![智能家庭Wi-Fi](https://images.unsplash.com/photo-1558002038-1055907df827?auto=format&fit=crop&w=800&q=80)

在折腾智能家居和家庭防盗的圈子里，大家一定被以下这几个痛点折磨过：

1. **“卧室浴室监控难”**：为了安全，你想在家里放满监控摄像头。但卧室、浴室这种极度隐私的区域，哪怕你买再安全的大厂摄像头，心里总有一丝担心：“这玩意万一哪天被黑客黑了，全家不就成网络直播现场了？”
2. **“红外探测器（PIR）是人工智障”**：普通的红外人体感应器不仅丑陋，而且极容易误报。家里养个猫狗乱跳，或者窗帘被风吹一下，你的手机就会疯狂收到警报，经常“狼来了”。
3. **“雷达组网代价昂贵”**：你想着用专业的微波雷达（毫米波雷达），结果发现不仅硬件极贵，还需要在墙上重新走线、打孔，对于已经装修好的家来说简直是灾难。

**难道就没有一种既不需要摄像头、又不需要重新布线、甚至能做到 100% 绝对保护隐私的家庭人体监测方案吗？**

就在今天，GitHub 榜单爆出硬核神作——**ESPectre**（ESP 幽灵探测器）！

它的底层逻辑堪称科幻：**“只要你家里有 Wi-Fi 信号，一切移动皆无所遁形！”**

它不需要任何摄像头，也不需要昂贵的雷达。它仅仅利用一块十几块钱的 ESP32 微控制器，去捕捉和分析家里 Wi-Fi 信号在空气中传播时的微小物理扰动（CSI 信号），就能精准知道家里哪里有人在走动、甚至能知道你有没有在呼吸！

## 降维打击：大白话拆解 ESPectre 的“空气水波纹雷达”

很多人觉得不可思议：Wi-Fi 怎么可能拿来当雷达用？

其实，它的底层逻辑极其精妙。我们用“水池里泛起的波纹”这个大白话例子，两分钟给你讲得明明白白。

### 1. 传统 Wi-Fi：水池里平静的水
你家里的无线路由器和你的手机、电脑之间，无时无刻不在通过看不见的电磁波进行通讯。这就好比一个水池，路由器在源源不断地荡起均匀的水波纹。

### 2. 人体移动：扔进水池里的石头
当家里空无一人时，Wi-Fi 的波纹传播路径是固定且完美的。
*   **干扰发生**：一旦有人走入这个房间，人体（主要是身体里的水分）会吸收、反射和阻挡这些 Wi-Fi 电磁波。这就像一个人跳进了水池，水波纹瞬间变得杂乱无章，产生了各种折射和反射。
*   **CSI 信号分析**：ESPectre 的核心，就是去抓取 Wi-Fi 信号的“物理指纹”——**信道状态信息（Channel State Information, CSI）**。
*   **AI 频谱诊断**：它把这些乱掉的“水波纹数据”实时送入轻量级频谱分析算法中。算法会瞬间认出：`“这个波纹特征是有人走过”`、`“这个波纹特征是猫在跳跃”`、`“这个微小的起伏是人类在呼吸”`。
*   **零侵入，高精度**：没有摄像头，只有一堆电磁波的物理数据，隐私泄露风险彻底为零！

## 保姆级教程：三步制作你的“赛博Wi-Fi防盗网”

ESPectre 极其亲民，核心硬件只需要一块普通的 **ESP32-S3** 开发板（某宝上仅需 15 元左右）。

### 第一步：刷入 ESPectre 固件
1. 准备一块带 Wi-Fi 的 ESP32-S3 开发板，用数据线插在你的电脑上。
2. 打开 Chrome 浏览器，访问 ESPectre 的官方 Web 刷机工具页面。
3. 点击 **“Install”**，选择你的 ESP32 串口，等待进度条跑满。两分钟内，这块开发板就变成了一台高精度 Wi-Fi 雷达！

### 第二步：配网并连接 Home Assistant
1. 拔掉开发板，插在家里任意插座上供电。
2. 手机搜索并连接开发板发出的名为 `ESPectre-Setup` 的临时 Wi-Fi 信号。
3. 进入配网网页，填入你家里的 Wi-Fi 密码以及你的 **Home Assistant**（开源智能家居系统）的 MQTT 服务器地址。
4. 开发板会自动重启并融入你家里的无线网络。

### 第三步：在 Home Assistant 里实现智能防盗与联动
打开你的 Home Assistant 控制面板，你会发现自动多出了一个传感器：`sensor.espectre_motion`。
你可以直接在自动化（Automations）里配置：
```yaml
alias: "卧室 Wi-Fi 人体感应灯"
trigger:
  - platform: state
    entity_id: binary_sensor.bedroom_wifi_presence
    to: "on" # Wi-Fi 扰动检测到有人进入
action:
  - service: light.turn_on
    target:
      entity_id: light.bedroom_light
```
**当你有网线或供电时，开发板会静静隐藏在插座上。一旦有人潜入房间，房间里的 Wi-Fi 信号折射特征瞬间改变，卧室灯瞬间亮起，并给你的手机推送警报！**

如果你想让 AI 帮你设计或编写关于 Wi-Fi CSI 人体感应的数据处理算法，可以把这套**CSI 信号分析专家提示词**丢给大模型：

```markdown
# Role: Wi-Fi CSI 信号处理科学家 (CSI Signal Processor)

## Objective:
你的任务是解析从 ESP32 微控制器采集到的 Channel State Information (CSI) 原始数据，并设计滤波与分类算法，以识别室内的人体动作。

## Algorithm Constraints:
1. **降噪优先 (Noise Reduction)**:
   - 电磁波容易受家电（如微波炉）干扰。必须首先设计一个巴特沃斯带通滤波器 (Butterworth Bandpass Filter) 或卡尔曼滤波器，滤除 50Hz 以上的高频白噪声和 0.1Hz 以下的超低频背景漂移。

2. **特征提取 (Feature Extraction)**:
   - 从振幅矩阵和相位信息中，提取出主成分分析 (PCA) 的前 3 个特征值。
```

## 幽灵雷达的局限性与避坑指南

1. **“极度依赖稳定的 Wi-Fi 环境”**：如果邻居家的无线信号频道（Channel）跟你的重合度太高，或者你的路由器放置在承重墙后面信号极弱，会导致数据底噪过大，系统误报率飙升。
2. **“无法穿透重型承重墙”**：虽然 Wi-Fi 可以穿墙，但如果穿过两三堵混凝土承重墙，信号能量衰减极大，雷达的探测距离和精度会大打折扣。
3. **“初期调试需要耐心”**：每个房间的家具摆设、反光介质都不同，这会导致每个房间的 CSI 基准特征（Baseline）独一无二。你需要跑一遍房间的学习程序，才能让它完全认清“无人的时候长什么样”。
