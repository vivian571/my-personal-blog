## Agent-Reach：AI 智能体的“赛博千里眼”

![Agent-Reach架构](https://images.unsplash.com/photo-1518770660439-4636190af475?auto=format&fit=crop&w=800&q=80)

**Agent-Reach** 是一个专为个人和开发者设计的**轻量级全网信息探索框架**。

传统的 AI 联网工具，往往只是调用一下 Bing 或 Google 的 API 搜索接口，只能抓到干瘪的网页标题和摘要（Snippet）。

而 **Agent-Reach** 的逻辑完全不同：
它内置了一套基于无头浏览器（Headless Browser）与智能爬虫协议的**全网 Reach 引擎**：

1.  **主动深入探查（Deep Crawl）**：它不光能搜，还能自己点进网页深处。自动识别并避开弹窗广告、Cookie 遮罩，把最核心的文章正文、数据表格抓出来。
2.  **动态防封与隐私防护**：智能模拟人类浏览节奏，自动处理反爬虫验证，同时绝不泄露你的个人敏感信息。
3.  **结构化清洗输出**：抓回来的海量网页数据，会被它瞬间精炼成 Markdown、JSON 或简明摘要，直接喂给你的大模型或个人知识库。

## 手把手教学：如何让你的 AI 拥有 Agent-Reach 技能？

Agent-Reach 提供了极其简单的命令行接口（CLI）和 Python SDK。

### 1. 一键安装

```bash
pip install agent-reach
```

### 2. 命令行极速体验

假设你想让 AI 帮你在全网搜集最新的折叠屏手机测评：

```bash
agent-reach search "2026年最新折叠屏手机对比" --depth 2 --output review_summary.md
```

它会自动在后台打开浏览器、抓取前 10 个深度测评源、提取核心数据，并在 30 秒内在你本地生成一份完整的 `review_summary.md` 报告！

### 3. 在 Python 代码中作为 AI Agent 技能调用

```python
from agent_reach import ReachEngine

# 初始化探索引擎
reach = ReachEngine(headless=True)

# 定义要抓取和整理的任务
target_url = "https://example.com/latest-tech-news"
structured_data = reach.extract_structured(
    url=target_url,
    schema={
        "title": "文章标题",
        "key_takeaways": "核心要点列表",
        "metrics": "关键数据"
    }
)

print(structured_data)
```

## 终极福利：把这个“个人赛博助理信息提炼提示词”拷走！

有了 Agent-Reach 抓回来的网页内容，怎么让 AI 输出最接地气的整理报告？把下面这套**“生活助理信息提炼提示词”**存好：

```markdown
# Role: Personal Life & Information Executive Assistant

## Profile
你是一个极其干练、贴心的个人生活助理。你擅长将从互联网上抓取到的杂乱、琐碎的信息，提炼为逻辑清晰、重点突出、极具行动导向的决策简报。

## Information Processing Protocol
对于任何输入的网页抓取文本，请按照以下结构进行整理：

1. **⚡ 一句话核心结论 (Bottom Line Up Front)**：
   用最直白的语言，告诉用户最核心的结论（如：“推荐买 A 款，因为今天在促销且评价最好”）。
2. **📊 核心数据对比表 (Data Comparison Table)**：
   使用 Markdown 表格，列出关键维度（价格、优点、缺点、适用人群）。
3. **⚠️ 避坑提醒 (Critical Warnings)**：
   高亮指出网友或用户反馈中最频繁提到的 2-3 个真实大坑（如：“该景点下午4点后停止入园”）。
4. **🎯 建议下一步行动 (Actionable Next Steps)**：
   给出 1-2 条明确的行动建议。

---
## Raw Input Text
请处理以下抓取到的信息：【在此粘贴 Agent-Reach 抓取到的网页文本】
```
