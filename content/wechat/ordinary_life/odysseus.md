## Odysseus：你的第一个 100% 局域网 AI 个人操作系统

![本地城堡](https://images.unsplash.com/photo-1558494949-ef010cbdcc31?auto=format&fit=crop&w=800&q=80)

简单来说，**Odysseus** 是由 `pewdiepie-archdaemon` 团队开源的一款**本地优先、隐私至上（Privacy-First）的 AI 个人工作台**。

它可不是一个简单的“套壳聊天网页”，而是一个把所有日常功能全部打通的**“私人操作系统”**。

在 Odysseus 的世界里，你拥有以下四大核心武器：
1.  **统一智能中枢 (Unified Workspace)**：把 AI 聊天、富文本编辑器、电子邮箱客户端、个人日历和待办清单全部揉在了一个界面里。
2.  **100% 本地大脑 (Local-First)**：深度适配 Ollama、llama.cpp 和 vLLM。只要你的显卡够用，你就可以断网运行最强本地模型（如 Qwen 或 Llama-3），数据这辈子都别想飞出你的局域网。
3.  **多智能体协作 (Deep Research)**：内置了本地 Agent 工作流。只要你给它一个任务，它会自动利用本地的 SearXNG（开源搜索引擎）去全网搜集资料，帮你生成深度研究报告。
4.  **无广告、无订阅、零追踪**：代码完全开源，不需要绑定任何信用卡，没有烦人的月费账单。

## 大白话拆解：它是怎么在本地当好你“全能管家”的？

![底层机制](https://images.unsplash.com/photo-1526374965328-7f61d4dc18c5?auto=format&fit=crop&w=800&q=80)

把这么多复杂的功能塞进一台电脑，而且还要全本地运行，它的底层逻辑到底是怎么跑的？
我们用大白话来拆解一下 Odysseus 的三驾马车：

### 1. 本地大模型作为“决策中枢” (Inference Engine)
就像人类的脑干，它负责理解你的命令。Odysseus 会通过 API 挂载你的本地 Ollama 服务。
当你输入：“帮我把下周二下午 3 点的会议记到日历上”，这个指令会被发送给本地模型。模型通过自然语言解析，提取出时间（下周二 15:00）和事件（会议）。

### 2. 本地数据库作为“永恒记忆” (Vector & SQL Database)
以前的本地 AI 聊完就忘，因为它们没有外挂存储。
Odysseus 在本地启动了 ChromaDB（向量数据库）和 SQLite。
它会悄悄把你写过的日记、收发过的邮件、甚至你的日历日程全部整理并做成数字指纹（向量索引）。
当你下次问它：“我上次去医院检查是什么时候？”它会瞬间去本地库里把当时的邮件和日程翻出来告诉你。

### 3. 多工具桥接器 (FastAPI & Agent Tooling)
模型解析出你要“记日记”或“发邮件”后，它不能直接操作软件。
Odysseus 在底层用 Python FastAPI 搭建了一套“工具执行器”。模型写好指令，执行器立刻去修改本地的日历文件，或者通过你的本地 SMTP 服务器把邮件发出去。

## 手把手教学：Docker 一键搭建你的赛博城堡

Odysseus 的设计非常现代化，完全基于 Docker-Compose 进行一键容器化部署。下面是保姆级搭建步骤：

### 1. 确保安装好 Docker 和 Ollama
在你的电脑上安装好 Docker Desktop，以及本地的 Ollama 并下载好模型：

```bash
# 启动 Ollama 并下载目前最强的本地中文模型 Qwen
ollama run qwen2.5:7b
```

### 2. 克隆项目到本地
打开终端，运行：

```bash
git clone https://github.com/pewdiepie-archdaemon/odysseus.git
cd odysseus
```

### 3. 配置本地环境变量
在项目目录下复制一份配置文件：

```bash
cp .env.example .env
```
用编辑器打开 `.env`，修改大模型指向你的本地 Ollama 地址（局域网 IP）：

```env
OLLAMA_API_BASE=http://host.docker.internal:11434
DEFAULT_MODEL=qwen2.5:7b
SEARXNG_URL=http://localhost:8080
```

### 4. 一键启动容器集群
```bash
docker-compose up -d
```
Docker 会自动在后台拉取并运行网页前端、FastAPI 后端、Chroma 数据库以及 SearXNG 本地搜索引擎。
当看到所有容器状态为 `Running` 时，在浏览器输入 `http://localhost:3000`，你就能看到精美、极简的 Odysseus 私人城堡工作台了！

## 场景实操：在平凡日子里，体验 100% 隐私的 AI 助理

有了这个本地大管家，你的日常生活会有什么改变？我们来看三个最温暖的真实场景。

### 案例一：完全隐私的“日记情感疗愈室”
*   **痛点**：今天在工作里受了委屈，你想写篇日记倾诉一下，顺便让 AI 给你提供点情绪价值。但你非常害怕日记上传到 OpenAI 后被用于模型训练，甚至遭遇隐私泄露。
*   **神操作**：
    打开 Odysseus 的本地富文本编辑器，新建一篇日记。
    在右侧的 AI 助手中，让它读取当前日记并对话。因为一切数据都运行在你桌子底下的这台电脑里，你甚至可以断开网线！
    你可以毫无保留地倾诉任何秘密，本地的 Qwen 模型会用温柔的语调安慰你，并帮你把日记里的负面情绪提炼成明天的待办清单。安全感直接拉满！

### 案例二：邮件与日程自动联动，拒绝“会议冲突”
*   **痛点**：客户给你发了一封邮件，说：“我们下周三下午两点开会讨论方案。”你需要手动复制，打开日历软件，找到下周三，再手动建一个日程，非常繁琐。
*   **神操作**：
    在 Odysseus 的内置邮件客户端里，你直接在邮件下方呼唤 AI 助手：“帮我安排这个会。”
    本地 Agent 会自动扫描邮件内容，查阅你本地的日历数据库，发现你下周三下午两点刚好有另一个会。
    它会弹窗提醒你：“⚠️ 注意，下周三下午两点与‘部门周会’冲突，是否需要自动起草一封邮件给客户协调时间，或者直接记录在备选日程中？”
    你点一下确定，它就把一切都帮你办妥了！

### 案例三：无网环境下的“超级本地学术研究”
*   **痛点**：你在坐飞机或高铁，网络极差甚至完全没网。但你需要写一份关于“区块链智能合约安全性”的深度研究报告。
*   **神操作**：
    在上车前，你把几十篇相关的 PDF 论文拖进 Odysseus 的本地知识库。
    在没有网络的环境下，你直接输入：“根据我导入的 PDF 论文，整理出一份对比表格，分析各个漏洞的防范机制。”
    本地的向量数据库和 Qwen 模型会静悄悄地帮你做全文检索、抽取要点，并在几秒钟内给你生成一份极具专业水准的 Markdown 报告！

## 终极福利：把这个“个人日常待办清单规划提示词”拿走！

如果你暂时没有部署 Odysseus，也可以复制这套**“奥德修斯个人待办规划提示词”**发给任意大模型，让它以本地管家的身份，帮你用最科学的方法规划你平凡日子里的每一天！

```markdown
# Role: Odysseus Cyber-Butler (Daily Life Architect)

## Objective
你是一个个人 AI 操作系统（Odysseus）的核心助理大脑。你的任务是帮我将一堆混乱的生活琐事、工作任务和待办事项，整理成一份逻辑严密、不拖延、且高度隐私安全的“每日运行计划表”。

## Structuring Principles
1. **防拖延沙漏 (Time-Blocking)**：拒绝只列任务不列时间。必须为每项任务规划具体的执行时间段，并预留 20% 的“呼吸缓冲时间”。
2. **任务分类罐 (Task Buckets)**：将任务划分为：
   - 🎯 **核心战役** (High Impact: 今天必须搞定的 1-2 件事)
   - 🔧 **日常杂务** (Maintenance: 邮件、整理、琐事)
   - 🌿 **生活充电** (Recharge: 运动、阅读、休息)
3. **隐私脱敏建议**：如果我输入的待办里包含敏感信息，请教我如何将其用“代号”替换。

## Output Format
请严格按照以下格式输出你的规划报告：

### 🎯 1. 今日核心战役 (Today's Big Wins)
*   [核心任务] -> 预计耗时 -> 目标交付物

### ⏳ 2. 时间卡片排班表 (Time-Blocked Schedule)
```text
09:00 - 10:30 | 🎯 核心战役执行
10:30 - 11:00 | 🌿 缓冲与休息
11:00 - 12:00 | 🔧 日常杂务清理
```

### 🔑 3. 局域网执行备注 (Local Execution Tips)
*   给我提 2 条如何利用本地电脑专注办公、减少噪音干扰的具体建议。

---
## Input Tasks
【在此输入你今天乱七八糟的想法和任务清单】
```

## 避坑指南：自建城堡的“维护成本”

虽然 Odysseus 听起来是一座完美的避风港，但也需要注意以下现实局限：

1.  **硬件配置的“隐形门槛”**
    想要在本地流畅运行 7B（70亿参数）以上的优秀模型，你的电脑最好配有 16GB 以上的内存，以及显存（VRAM）在 8GB 以上的显卡（如 NVIDIA RTX 3060 以上，或苹果 M 系列芯片）。如果你的电脑是多年前的集成显卡老电脑，运行本地模型可能会卡成幻灯片，语速比树懒还要慢。
2.  **没有自动备份**
    因为它是 100% 本地运行，你的数据全部保存在你的这台电脑上。如果你的硬盘突然坏了，或者你不小心把 Docker 容器的数据卷删除了，你的所有日程、笔记和邮件记录将**彻底消失，无法找回**。因此，**一定要养成定期备份 Docker 数据卷的习惯**！
