## 大白话拆解：Kaneo 是怎么帮你拯救混乱生活的？（看板四象限法）

![四象限法](https://images.unsplash.com/photo-1506784983877-45594efa4cbe?auto=format&fit=crop&w=800&q=80)

为了让大家听懂，我们用最接地气的“大白话”来拆解一下 Kaneo 是怎么帮你理清生活的：

人的精力是极其有限的，你的大脑是用来“思考”的，而不是用来“储存琐事”的。
Kaneo 的底层逻辑，其实就是帮你搭建了一个**“赛博四象限分类收纳盒”**：

1.  **收件箱 (Inbox - 脑袋清空区)**
    当脑子里突然蹦出一个念头（比如“下周给妈妈买生日礼物”），不要试图去记它！
    按快捷键一秒敲进 Kaneo 的 Inbox 栏里。这一刻，你的大脑瞬间释放内存，恢复平静。

2.  **待办区 (To-Do - 目标清晰区)**
    每天早上喝咖啡时，花 2 分钟把 Inbox 里的杂事拖拽到“今日待办”。
    设置优先级：红色的高优先（今天必须做），蓝色的低优先（有空再做）。

3.  **进行中 (In Progress - 专注区)**
    这一栏永远只放 **1-2 个任务**！
    做哪件事就把哪张卡片拉进来。这会给你极强的心理暗示：“我现在的任务只有这一个，其他事都和我无关。”

4.  **已完成 (Done - 获得感区)**
    做完一件事，把它爽快地拖进 Done 栏！
    看着“已完成”列表里越堆越高的卡片，那种踏实、满足的成就感，会给你源源不断的正反馈，彻底告别推延症！

## 手把手教学：如何 3 分钟部署你的专属 Kaneo 任务大脑？

因为 Kaneo 提供了极其成熟的 Docker 镜像，部署起来极其简单！

### 第一步：准备 Docker 环境

确保你的电脑或服务器上安装了 Docker 和 Docker Compose。

### 第二步：创建配置文件 `docker-compose.yml`

新建一个文件夹，里面创建一个 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  kaneo:
    image: kaneo/kaneo:latest
    container_name: my_kaneo
    ports:
      - "8080:3000"
    environment:
      - NODE_ENV=production
      - DATABASE_URL=file:/app/data/kaneo.db
    volumes:
      - ./data:/app/data
    restart: always
```

### 第三步：一键启动

在终端中运行：

```bash
docker-compose up -d
```

镜像拉取完毕后，在浏览器输入 `http://localhost:8080`，你就拥有了一个完全属于你自己的、数据绝对隐私安全的个人任务大脑！

```markdown

## Structuring Format
对我的输入进行整理时，请严格按以下结构输出：

### 📥 1. 任务拆解与优先级矩阵 (Eisenhower Matrix)
- **🔴 P0 - 紧急且重要 (今天必须做，控制在 3 件以内)**
- **🟡 P1 - 重要不紧急 (长期有价值，规划进本周行程)**
- **🟢 P2 - 琐碎杂事 (顺手做或委派出去)**

将上述事项转换为可以直接导入/复制到 Kaneo 看板的格式：

- **子任务清单 (Checklist)**:
  - [ ] 步骤 1 (预估 15 分钟)

- **分类标签 (Tags)**: `#工作` `#生活` `#健康` `#财务`
```
