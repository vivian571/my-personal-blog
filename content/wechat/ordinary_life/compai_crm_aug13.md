## 怎么用

### 第 1 步：装上 Skill / Docker 一键部署

在你的服务器或本地电脑上运行 Docker 命令：

```bash
git clone https://github.com/trycompai/crm.git
cd crm
docker-compose up -d
```

> 💡 **提示**：不需要复杂配置，Docker 会自动帮你在本地跑起前端 Web 界面与后端数据库，1 分钟内搭建完毕！

---

### 第 2 步：做变量替换 / 配置 AI Key

打开浏览器访问 `http://localhost:3000`：
(1) 注册并登录管理员账号；  
(2) 在【设置 ➔ AI 服务】中填入你的 OpenAI 或 DeepSeek API Key（用于智能提炼聊天纪要与生成问候草稿）。

---

### 第 3 步：改问题，靠脑力干 / 建立你的第一个好友档案

*   点击【添加联系人】，输入名字：`老李`。
*   在备注文本框里粘贴随手记的散乱信息：“今天和老李喝咖啡，他刚换了新工作去了一家 AI 创业公司，下个月 15 号生日。”
*   点击【AI 智能归档】，系统瞬间为你生成了老李的结构化档案，并在后台自动建立了“15号生日问候”的定时关怀任务！
