## Agent-Memory：把 AI 记忆打造成“四大终极资产”

![四大资产](https://images.unsplash.com/photo-1451187580459-43490279c0fa?auto=format&fit=crop&w=800&q=80)

**TencentDB Agent-Memory** 并不是又一个简单的向量数据库包装，而是一套**团队级 AI 记忆治理与资产化框架**。

它最惊艳的创举，就是把人类与 AI 互动产生的庞杂信息，精准地分类提炼成了**四大“赛博记忆资产”**：

1.  **Chat Memory（对话偏好记忆）**：记住你的个人喜好、审美倾向、工作习惯和历史决定。（例如：“主公喜欢日系清新风的风光色彩调校”）。
2.  **Skill Assets（技能资产）**：把 AI 在过去成功解决复杂问题的步骤，打包提炼成可复用的“技能卡片”。
3.  **LLM-Wiki（赛博知识百科）**：把零散的聊天记录和文档，自动整理成结构清晰、带双向链接的知识百科。
4.  **Code-Graph（代码图谱资产）**：把庞大的代码结构转化为直观的关系网络，让 AI 永远记住代码的骨架。

## 大白话拆解：它是怎么把聊天记录变成“记忆资产”的？

![记忆提炼拆解](https://images.unsplash.com/photo-1509228468518-180dd4864904?auto=format&fit=crop&w=800&q=80)

为了让大家听懂，我们用最接地气的“大白话”来拆解一下 Agent-Memory 的运作机制：

假设你的 AI 助手是一个**刚入职的摄影助理（AI）**：

*   **没有记忆库时**：
    你每天都要一遍遍提醒他：“我不喜欢饱和度太高的风景照！把高光调低一点！”
    助理每天听完就忘，第二天依然给你交来大红大绿的俗套照片。

*   **有了 Agent-Memory 之后**：
    *   **夜间沉淀 (Chat Memory)**：每天下班后，记忆引擎会自动扫描今天你和助理的所有对话。它提炼出：“老板对风光照的审美是：低饱和度、高暗部细节。”并把这条规则永久写入 `Chat Memory`。
    *   **总结招式 (Skill Asset)**：当助理今天成功用 Python 批量处理好了一万张风景照的 EXIF 信息时，记忆引擎自动把这段成功代码封装成 `ExifExtractSkill`。
    *   **编撰百科 (LLM-Wiki)**：把你顺口聊到的“云南大理最佳拍摄机位”，自动归类到 `LLM-Wiki/旅行指南/云南` 页面下。

第二天，哪怕你换了个新的 AI 助手，只要接入了这个记忆库，新助手瞬间继承所有的记忆与技能，上手就能为你拍出完美大片！

## 手把手教学：如何让你的 AI 接入 Agent-Memory？

项目提供了极其标准的 Docker 部署与 Python SDK 接入方式。

### 第一步：启动 Agent-Memory 服务容器

```bash
docker run -d \
  --name agent-memory \
  -p 8000:8000 \
  -v ./memory_data:/app/data \
  tencentcloud/agent-memory:latest
```

### 第二步：在 Python 中调用记忆 SDK

```python
from agent_memory import MemoryClient

# 连接本地记忆库服务
client = MemoryClient(endpoint="http://localhost:8000")

# 1. 写入一条个人审美偏好记忆
client.add_chat_memory(
    user_id="user_123",
    content="我在处理美丽好风景图片时，偏好莫兰迪色系，不喜欢过于艳丽的饱和度。"
)

# 2. 检索记忆：当 AI 准备生成回答时，先查询记忆
memories = client.search_memory(
    user_id="user_123",
    query="用户对风景图片的色彩要求是什么？"
)

print("AI 检索到的记忆：\n", memories)
```

通过这几行代码，你的 AI 在回答任何问题前，都会先查阅这个“记忆库”，从而输出完全符合你心意和偏好的内容！
