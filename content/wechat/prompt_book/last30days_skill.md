## 降维打击：大白话拆解 last30days-skill 的“情报拼图算法”

很多同学好奇：一个 AI 提示词包，是怎么做到横跨这么多平台，还能把信息整理得有条不紊的？

这得归功于它的**“多源情报拼图”**底层逻辑。我们用“侦探破案”的例子给你解构：

### 1. 传统 AI 搜索：只听官方证词的糊涂法官
传统 AI 联网搜索，就像破案时只问被告（官方发布会）：“你做错了吗？”。得到的一定是“毫无问题，完美无瑕”。

### 2. last30days-skill：走街串巷、监听全网的“福尔摩斯”
它通过以下四步完成情报的拼图：

*   **第一步：全渠道广播检索 (Multi-Channel Dispatching)**：
    它不会只发一个搜索请求。它会针对你的主题，自动派生出多维度的“平台特异性检索”。例如：去 Reddit 搜“Dislike/Issue”；去 X 搜“Debate/Hot thread”；去 HackerNews 搜“Under the hood”。
*   **第二步：交叉火力校验 (Cross-Verification)**：
    如果一个关于某大模型性能的爆料在 X 上有，但 Reddit 技术版说“这不可能”，HackerNews 贴出了源码分析，AI 会在后台自动标记这三方的冲突，绝对不听信单一信源。
*   **第三步：预测市场对齐 (Polymarket Alignment)**：
    这是这个项目最绝的地方！它会去查 Polymarket 这样的预测市场。因为这里的人都是真金白银在下注，赔率数据往往比任何大 V 的分析都更接近未来的事实。
*   **第四步：接地气叙事合成 (Grounded Synthesis)**：
    最后，它把所有野生的讨论、专家的硬核吐槽、以及预测市场的胜率，融合成一份完全不注水的报告，直接提取出最有价值的 5 个核心结论。

## 保姆级教程：从零用 last30days-skill 起底任意话题

这套系统目前以 AI Agent 技能库的形式开源。我们可以快速部署它。

### 第一步：克隆并安装运行库
打开终端（需要 Python 环境）：

```bash
# 1. 克隆代码
git clone https://github.com/mvanhorn/last30days-skill.git
cd last30days-skill

# 2. 安装配套的搜索引擎与解析依赖
pip install -r requirements.txt
```

### 第二步：配置你的搜索 Token 与底座
你需要一个可以联网的 AI 环境。这个项目默认支持通过 Tavor 或者 Tavily 这样的 AI 专属搜索引擎 API 进行高品质数据提取。在 `.env` 中填入你的 Key：

```bash
TAVILY_API_KEY=你的联网搜索引擎Key
OPENAI_API_KEY=你的大模型Key
```

### 第三步：输入你想起底的話题，静待结果
在命令行直接启动研究：

```bash
python run_research.py "最近30天全网对 Tailwind CSS v4 的最真实吐槽是什么？"
```

你会在屏幕上看到 AI 像雷达一样扫描各大阵地：
*   `[Reddit] 扫描到 15 条关于配置太复杂的抱怨`
*   `[HackerNews] 提取到关于 Rust 编译器性能的深入讨论`
*   `[X] 获取到前端大 V 对全新 OKLCH 色彩的狂热赞美`
*   **只需 15 秒，一份详实的“反套路研究报告”直接生成在你的本地桌面上！**

## 凡事皆有代价：情报收集器的局限性与警示

1. **“信息茧房的杂音”**：论坛讨论往往容易情绪化，Reddit 上也充斥着喷子。你需要保持理智，AI 收集来的“吐槽”很多时候只代表部分用户的极端情绪，需要你做二次客观过滤。
2. **“网络与 API 限制”**：由于 X 和 Reddit 近年限制了爬虫，如果你的联网搜索接口（如 Tavily）额度用光，AI 只能回退到普通的谷歌抓取，效果会打一定折扣。
3. **“时效性墙壁”**：它最擅长起底“最近30天”的短周期情报。如果你想查几年前的历史文献或者长跨度的宏观趋势，还是得老老实实去查数据库和学术文献库。

**总结：这套方案让我们在信息洪流中，拥有了一双能够直接穿透公关软文、看清事物本质的“透视眼”！**
